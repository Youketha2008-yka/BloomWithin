# BloomWithin upgraded demo

## Run locally in VS Code
1. Extract the ZIP into a folder.
2. Open that folder in VS Code (`File > Open Folder`).
3. Open `index.html`.
4. Right-click in the editor and choose **Open with Live Server**. If that command is missing, use `Ctrl+Shift+P`, type `Live Server: Open with Live Server`, and run it.
5. The site should open in your browser.

## Publish to Netlify
This is a static site. Upload the three files (`index.html`, `style.css`, `script.js`) to your Netlify site's deploy area, or drag the extracted folder into Netlify Drop to create a separate deploy. To update the existing site, use the existing Netlify site's Deploys page and upload the folder there. Keep a backup of your current version first.

## Demo storage and safety
- Demo entries are saved in this browser using localStorage; they do not sync across devices.
- Use fictional information only. This is not a secure health record.
- Remo uses preset responses, not a live AI model or clinician.
- The site provides general education only, not diagnosis or personalised treatment.
- The Tamil selector is marked as coming soon; the site content is currently in English.
